# Threat model section 5: test map

Which tests exercise each numbered requirement of `threat-model.md` section 5 (state of 2026-11-15). Paths are relative to `crates/`; `file::test_fn` names a test function in that file. Status: `covered` means a test checks the whole claim, `partial` some clauses only, `none found` no test. The map was drawn up by reading test names and doc comments; every function name was checked to exist, but not every body was read against its row, so treat a `covered` as "a test of that claim exists" and re-read the test before relying on it for a release decision. Item 12 (a TLS inspecting proxy) is `menzil-node/tests/inspecting_proxy_live.rs`, which also carries mutant proofs: a relay or node that ignores a failed decrypt fails it.
